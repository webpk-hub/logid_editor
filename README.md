# LogiD Config GUI Editor

A lightweight, user-friendly graphical interface to edit `logid.cfg` files for `logiops`. No more manual editing of complex configuration files!

## ✨ Features
- **Easy Editing**: Modify DPI, Smartshift, and Hiresscroll settings via checkboxes and input fields.
- **Button Mapping**: Easily manage button CIDs and key combinations in a table view.
- **File Management**: Open any `.cfg` file from any directory.
- **One-Click Save**: Automatically formats the output to match the required `logid` syntax.
